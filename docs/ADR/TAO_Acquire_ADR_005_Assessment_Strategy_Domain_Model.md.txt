TAO Acquire – Assessment Strategy Domain Design

Document ID: TAO-AQ-DD-005
Version: 1.0 (Draft)
Status: Approved for Implementation
Owner: TAO Architecture

1. Purpose

This document defines the proposed domain model for Assessment Strategy, which represents the final planning artifact produced by TAO Acquire before candidate invitations and serves as the contract between TAO Acquire and TAO Assess.

The objective is to establish a domain model that:

follows DDD principles
remains simple for the MVP
supports recruiter customization
provides a stable contract for TAO Assess
allows future AI learning without redesign
2. Position within TAO

Recruiters may modify every part of the Assessment Strategy.

Examples:

11. Design Decisions
Assessment Strategy belongs to TAO Acquire

Reason:

It represents planning, not execution.

Assessment Strategy is the contract for TAO Assess

Reason:

Assessment execution should not infer assessment plans.

Assessment Round is an Entity

Reason:

Each round has its own identity, lifecycle within the aggregate, and may be independently edited by recruiters.

Competencies remain JSON for MVP

Reason:

Keeps implementation simple while retaining flexibility.

AI returns Structured JSON

Reason:

Provides a stable machine-readable contract.

Markdown stored separately

Reason:

Supports recruiter review and future reporting.

Two-table design

Reason:

Normalized enough for production while avoiding unnecessary complexity.
